OpenCode Breach Response Blocked by Frontier Model Safety Refusals, Defenders Switched to OpenAI Daybreak Blue

Date: 2026-10-21
Tags: llmjacking

Executive Summary

New reporting adds operational detail to the OpenCode Console breach: attackers ran a large scale distillation attack and stole stored API keys for users who linked external providers, and OpenCode incident response stalled because frontier AI models began refusing investigation requests as the work turned to potentially malicious code. OpenCode stabilized the response only after gaining access to OpenAI Daybreak Blue, a program giving vetted defenders models with fewer restrictions. The breach affected 1.4 percent of OpenCode Console users, with some reporting more than $1,700 in unauthorized charges overnight.

Detailed Findings

OpenCode, an open source AI coding agent, disclosed that its systems were compromised in what it described as a large scale distillation attack that exposed stored API keys belonging to users who linked external providers including OpenAI, Anthropic, and Google bleepingcomputer.com. According to OpenCode, the breach affected 1.4 percent of OpenCode Console users and the project notified them by email; users who received no email were not affected. Multiple users reported unauthorized API charges and suspended projects in Google Cloud, with some reporting more than $1,700 in unauthorized charges overnight. The vendor email states the earliest possible key exposure was October 17, 2026 at 00:30 UTC and that no data appears to have been exposed. OpenCode co-founder Dax Raad said attackers targeted the company systems for at least 48 hours using AI agents and that the investigation was blocked when the AI models being used began refusing requests due to built in safety safeguards as the work turned to potentially malicious code axios.com. Raad said the situation stabilized after OpenCode began using OpenAI Daybreak Blue, a cybersecurity program that gives vetted defenders access to models with fewer restrictions. OpenAI, Google, and Anthropic said they worked with affected customers to revoke exposed API keys and address unauthorized usage charges. OpenCode said it was working with the three providers but could not share further details at the time.

Detection Recommendations

Revoke and rotate all provider API keys linked to OpenCode Console accounts, then review Google Cloud, OpenAI, and Anthropic billing for unexpected usage or suspended projects. Monitor for anomalous spend spikes tied to leaked keys and set hard budget caps and alerts on AI provider accounts. For incident responders, confirm that the AI models used for defensive analysis permit work on potentially malicious code so that response is not blocked mid investigation, and track access to restricted defender programs for such cases.

CrowdStrike Links South Korean Bank Breaches to ARTEX AI Pentest Tool, Claude Code and Multiple LLMs

Date: 2026-10-11
Tags: malicious-tool, shadow-ai

Executive Summary

CrowdStrike reported that the operator behind late September and early October 2026 breaches of South Korean banks and savings banks chained ARTEX, a Chinese open source AI penetration testing tool, with Anthropic's Claude Code and several large language models including DeepSeek v4.1-flash, GLM-5.3 and Grok 4.6. Seven Korean financial firms and about 66,000 customers were affected. Defenders should treat exposed AI agent session logs, configuration files and memory files as operational artifacts and watch for unauthorized LLM API use inside intrusion activity.

Detailed Findings

CrowdStrike's threat intelligence unit, in a report released on October 7 2026, analyzed the wave of breaches that hit South Korean banks and savings banks from late September into early October 2026 tenbrief.com. Korean regulators and the affected companies reported that seven financial firms and about 66,000 customers were impacted tenbrief.com. CrowdStrike assessed with moderate confidence that a single Chinese speaking operator motivated by money ran the campaign, and did not name a group tenbrief.com. The toolkit combined ARTEX, an open source AI penetration testing tool built in China that autonomously hunts for and exploits weaknesses in specific services, with Anthropic's Claude Code coding agent tenbrief.com. ARTEX ran mainly on DeepSeek v4.1-flash accessed through a reseller, with Zhipu AI's GLM-5.3 and xAI's Grok 4.6 used as helper models in additional sessions tenbrief.com. The evidence came from the attacker's own infrastructure: a publicly browsable directory on one server held Claude Code conversation logs, ARTEX configuration files, AI memory files carried between sessions and a Chinese language prompt document instructing LLMs how to run a penetration test; a pointer led to a second Hong Kong server that acted as the main hub holding the record of the operation, plus a proxy list of nine IP addresses used to hide the real location tenbrief.com.

Detection Recommendations

Monitor authentication and process telemetry on internet facing financial services for autonomous scanning and exploitation patterns consistent with an AI pentest agent. Hunt for unexpected outbound API traffic to third party LLM and AI coding agent endpoints from server and administrative hosts. Treat exposed or unexpected AI agent artifacts (Claude Code session logs, agent memory files, pentest tool configuration) on internal or internet facing systems as incident indicators, and restrict who can install or run AI coding agents on production and administrative hosts. Baseline and alert on proxy use from administrative segments that masks origin location.

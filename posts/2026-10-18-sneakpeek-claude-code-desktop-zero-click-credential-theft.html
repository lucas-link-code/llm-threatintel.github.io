SneakPeek Zero Click Flaw in Claude Code Desktop Exfiltrates Developer Credentials

Date: 2026-10-18
Tags: malicious-tool

Executive Summary

Noma Security found a zero click data theft flaw, dubbed SneakPeek, in Anthropic's Claude Code Desktop preview pane that silently steals SSH private keys, AWS credentials and Claude OAuth tokens from developer machines. Three chained architectural gaps let malicious HTML padded past 256KB load as file:// URLs, skip the content security policy and run embedded JavaScript with no user interaction. Anthropic fixed the issue in version 1.30096.1 after its first patch was bypassed.

Detailed Findings

According to darkreading.com, a high severity bug named SneakPeek in the Claude Code Desktop preview pane let an adversary steal sensitive files from developer machines with no prompt, no click and no sandbox defense. Noma Security researchers said three architectural flaws chained together bypassed built in sandbox protections: a missing content security policy, unrestricted origin access and inactive request filtering. Eli Ainhorn, senior AI vulnerability researcher at Noma, wrote that an attacker could deploy a standard looking public code repository containing an HTML file padded past 256KB with an embedded malicious script, and that when a developer asked Claude Code to review or edit the file the preview pane rendered it automatically and triggered silent background exfiltration of credentials. The script could steal AWS and GitHub credentials, API keys and Claude's own OAuth tokens. According to theinjection.dev, HTML files over 256KB loaded as file:// URLs, skipping the content security policy, so embedded JavaScript read SSH and cloud keys; Anthropic fixed this in version 1.30096.1. Dark Reading reported that Noma first reported the flaw to Anthropic on July 4, Anthropic pushed a first fix on July 9, Noma found a bypass on a July 24 re-test, and a final patch was deployed on August 17 ahead of the October advisory.

Detection Recommendations

Update Claude Code Desktop to version 1.30096.1 or later. Treat HTML files larger than 256KB from untrusted repositories as dangerous and avoid opening untrusted HTML in any AI assistant preview pane. Monitor for unexpected outbound connections from developer workstations and alert on JavaScript execution from file:// origins. Rotate SSH keys, cloud credentials and Claude OAuth tokens on any host that ran a vulnerable version.
